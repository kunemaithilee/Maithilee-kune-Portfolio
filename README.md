# Maithilee Kune — Portfolio

Personal portfolio built with **Next.js**, **React**, **Framer Motion**, **Three.js**, and **Tailwind CSS**.

## Tech Stack

- **Framework:** Next.js 15 (Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4
- **Animation:** Framer Motion, GSAP
- **3D:** React Three Fiber, Three.js
- **Icons:** Lucide React

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy

Hosted on **Vercel** — push to the `Maithilee` branch to trigger a deployment.
